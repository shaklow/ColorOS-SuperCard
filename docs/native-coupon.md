# 自研卡券（0.2.39）

`staging` 卡券接入 NativeCardHost，沿原配置排序，与 PAY、校园卡和 LENS 共用 288×466dp 卡片、跟手唤出、连续切卡及叠放收起。NativeCouponCard / NativeCouponSession 和私有 UI 的 CouponCardSurface 接管券列表、详情、返回、钱包入口与卡包内移除确认，不创建原券插件视图、TicketStackView 或混淆数据 bean。记忆等未迁移卡片启用时仍保留原完整卡包；原插件留作这条兼容路径。

继续使用 WalletCouponClient、WalletCouponBridge 和 CouponRefreshCoordinator 的既有握手、发送方校验、原生读取、账号确认和有限重试。打开整个自研卡包时刷新一次，切换前台卡片不重复查询。自研窗口以身份令牌持有刷新会话，原窗口的迟到显示/隐藏通知不能清理新窗口的数据；关闭整个卡包才结束该令牌。未挂载的预热视图不查询钱包。

保持电影票、演出票和消费券的原解析分组顺序、场所、时间范围与使用状态。相同账号的补码保留当前详情和滚动位置；锁屏、账号变化或无效快照清除旧券与选择。已使用或过期的券仍能查看元数据和钱包入口，不显示可扫描码。二维码仅来自钱包提供的原图、图像 URL 或实际 QR 内容；核销文字、识别文本和来源链接不用于造码。合法无码抖音券显示既有提示。

二维码解码在有界后台队列执行，切走、返回、关闭和数据变化取消旧任务；迟到结果必须核对当前券、账号和挂载代次。URL 图片复用已有 HTTPS、大小、超时限制，以账号和券标识区分缓存，支持按视图解绑。每次完整关闭或账号失效清理图片缓存。界面只接收框架 Bundle / View，钱包链接与二维码内容不传给私有 UI。

钱包查看只接受既有官方 RouterActivity 与经过验证的 ticket/unusedList 路径，其他来源退回钱包管理。原图只支持钱包元数据里的 content URI。移除沿用原隐藏偏好，只从超级卡包隐藏，保留钱包原券和原始截图，不调用钱包写入、已使用或截图删除接口。确认在受保护的卡片窗口内完成。

验证使用合成券数据及受控钱包传输，覆盖新旧窗口会话隔离、账号变化、移除失败、顺序筛选、QR 真实内容往返、原图和链接限制、详情操作与深浅色大字体。标准模拟器不等同于真实 ColorOS 钱包取券验收；当前无手机 ADB，不读取或操作用户真实票券。
