# 浮层重构验收范围

本轮收尾对应既定计划的四个阶段，保留原手势唤出、切卡、收起、窗口所有者、卡片设置、用户路由和解锁入口。卡券和记忆界面不改造，原厂 DEX 继续作为固定 ABI 输入。

| 阶段 | 实现与边界 |
| --- | --- |
| 共用外观参数 | 0.2.19 已将圆角、内边距、间距和设置触摸目标统一到资源，Kotlin 与 XML 使用同一组值 |
| 共用生命周期 | FloatingCardScope 统一监听、排队刷新、计时与异步结果令牌；校园卡和 LENS 接入，关闭后旧任务失效 |
| 底层桥接拆分 | PAY 安装协调、会话、任务选择/观察、显示 ABI、触摸策略分工明确；原启动就绪及 SDK 用户路由保留独立组件；Root 显示归属由固定 PAY/LENS 槽位管理 |
| 回归与兼容清理 | 离线 Hook/协议检查、实际 DEX ABI、API 31/36 单元测试、Android 36 安装回归、40 张既有 UI 渲染比较；删除错误 getter 别名回退和仅用于日志的 Compose 探测 |

## 相机问题

新增相机卡片内的真实系统相机显示与触摸，模式 Intent 不再经过原先的收起和主屏外跳流程。返回、切卡、隐藏和销毁清理会话，失败停留在卡片内。PAY 切卡保留显示，因此 LENS 有单独固定显示槽位，避免中断或阻塞原 PAY。详情见 [卡片内相机](lens-embedded-camera.md)。

## 保留的兼容入口

- NativeCardsActivity 仍为旧快捷方式提供透明跳转，属于外部入口，不能按源码调用数删除。
- UiCompat 仍被已补丁的内置 DEX 调用，ABI 检查和合包链接核对覆盖其使用。
- Root 显示 callback token 的隐藏 getter/字段回退对应不同系统框架实现，不属于已证实无用的原厂 DEX 别名。
- OplusIntent 和 SDK 用户 Context 的兼容分支继续服务现有 ROM；没有目标系统证据时不删除。
- 卡券及记忆插件仍有独立资源/加载器，保留各自生命周期和业务适配。

## 发布验收

发布前要求离线检查、Gradle 两模块测试、依赖隔离/资源/链接/签名验证及 Android 36 设备回归通过。设备回归对实际副屏中的 Activity 注入触摸并核对按钮计数，使用正式 LensDisplayBackend 的启动与输入接口；测试按既有 `settings_` 标签前缀定位控件，并等待内容、布局和窗口就绪。

标准模拟器没有 ColorOS 相机、Vector 和相机 HAL，自动化只能验证显示、输入、会话清理和安装链路，不能宣称特定 ColorOS 模式/拍照录像及 ROM 手势已完成真机验收。该硬件边界与本仓库可执行的重构验收分开记录，不跳过失败检查。
