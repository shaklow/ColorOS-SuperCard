# Material 卡片管理与功能设置

0.2.24 延续私有 Material 界面档案，覆盖管理列表、支付卡设置与 LENS 功能设置。卡券浮层、记忆卡片内容、PAY/LENS/校园卡运行窗口与唤出手势保持原样。

## 操作与入口

- 管理列表使用开关启用或停用，至少保留一张卡片；停用保留位置。
- 支付卡和 LENS 使用独立功能列表，支持开关、长按拖动及上移/下移。支付卡保留 1–6 项（原大指纹机型 1–4 项），LENS 保留 4–6 项。旧配置不足下限时可以逐步启用恢复，不重置数据。
- 仅展示原配置中设备支持的功能；LENS 沿用既有 ColorOS 模式映射，不重新探测或改变启动信息。隐藏功能、未知字段和皮肤配置保留原值。
- 首页及旧 `com.vivo.card.setting.CardSettingActivity` 进入管理页；旧 `com.vivo.card.setting.CardEditActivity` 通过 manifest alias 进入新功能设置页，继续使用原 `mCardType=pay/camera`。无效类型直接结束页面。原 DEX 和资源保留。
- 校园卡继续进入授权页，卡券保留钱包管理入口，记忆卡片没有新增编辑器。

## 保存与动效

操作后立即投影用户选择，保存过程中不恢复旧开关，不切换禁用颜色，不展示反复出现的加载提示。短暂保存期间只锁定输入，收到读回确认后恢复。失败会回到实际存储值并明确提示，不把本地显示误认为保存成功。

排序列保留原视图与焦点，只改变布局位置；按键和拖拽松手均从当前视觉位置平滑移动，连续排序从正在进行的位置衔接。拖动保留系统阴影并以手柄位置为锚点，源卡片降低透明度，结束后恢复。全局关闭动画时立即落位。脱离窗口时取消动画并清理回调。键盘和无障碍遍历顺序随视觉顺序更新。

## 配置与并发

沿用 `Settings.Secure.card_setting_data`，没有第二份数据库。编辑仅改变相应卡片/功能的 `enable` 或数组顺序，保留功能启动 `info`、能力标记、皮肤和所有未知字段。

仅在原配置缺失时调用既有首次初始化和 SharedPreferences 迁移。损坏、重复标识或非法开关不触发重置。所有存储读写位于工作线程，提交前比较原始快照、保存后读回确认。Settings 不提供跨进程 CAS，比较与写入之间仍有窗口；读回变化会报告失败并重新读取，不回滚其他编辑器的数据。页面关闭后不再应用结果，已接受的写入继续完成。

ContentObserver 通知先核对原始内容；已确认写入的延迟通知不禁用控件、不打断长按，真实外部修改仍刷新页面。未授权时可查看原配置，编辑不可用，并提供运行状态与权限入口。

## 验证

API 31/36 覆盖配置保留、数量边界、损坏和隐藏功能、保存期间稳定显示、排序视图复用、关闭动画、功能页深浅色和 320/600 dp 大字体布局。离线检查真实合包 manifest 与原 DEX 反射签名。

Android 36 安装回归覆盖即时开关状态、按键与真实拖拽的中间位移和最终落位、视图不脱挂、长按期间的重复通知、两个功能页及旧入口、外部配置刷新和首次初始化。发布时比较原设置/浮层渲染，并核对新增功能页。
